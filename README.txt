ARJUNPUR NABA JAGRATA SANGHA - Club Payment & Accounts App

এই প্রথম prototype-এ:
- Donation entry
- Monthly membership entry
- Expense entry
- Income/Expense/Balance dashboard
- Local transaction storage
- Basic printable receipt
- UPI payment button

গুরুত্বপূর্ণ:
1. app.js-এ YOUR-UPI-ID-এর জায়গায় ক্লাবের আসল UPI ID বসাতে হবে।
2. এটি prototype; UPI payment-এর automatic server-side verification এখনও যুক্ত হয়নি।
3. বাস্তবে online payment-এর জন্য একটি payment gateway/merchant account এবং secure backend প্রয়োজন।
